# V1 验证记录

验证日期：2026-10-28（Australia/Sydney）。

- 0.2.0 TypeScript 类型检查通过；44 项单元测试通过（包括 20 项新增解析、分组与填充回归场景）。
- 交互预览通过：7 项已有资料填写，3 项新答案填写，刷新后的 10 项答案复用、下拉答案以可读标签保存、编辑资料、撤销、备份及恢复。
- 真实 Chrome MV3 环境通过：原样加载生产 manifest，通过工具栏 action 获得 activeTab 权限；中英文 PDF 文字提取（含中文 CMap）、扩展 CSP、后台存储、内容脚本注入、导航后问答复用均通过。
- 检查 320px 与 400px 宽度，无横向溢出；已人工查看界面截图。
- 生产 manifest 没有 host_permissions。全量 PDF 依赖随扩展打包。
- 中文 PDF 中教育仅提取学业字段，工作/实习独立分类，两个项目分别产生六类字段；浏览器验证缺失字段补充、分组保存及重复导入去重。
- 在真实 MV3 扩展中导入中文样本，遇到多个项目时不自动选择；手动指定同一项目的六条资料后六项填充成功，未创建跨项目通用记忆。

浏览器测试使用 Playwright 和隔离的 Chrome 测试资料目录。当前环境下载的 Chrome for Testing 存在 Windows Side-by-Side 启动错误，测试已通过内置回退流程改用本机 Chrome 156；未使用日常浏览器资料目录。源代码中的回退流程可直接复用。

以上结果来自本地测试表单和独立扩展测试环境，尚未逐站适配实际招聘网站。自定义控件、复杂 PDF 排版、OCR 和 iframe 等边界详见 V1 设计文档。

pnpm typecheck
